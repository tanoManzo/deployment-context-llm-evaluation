# Deployment-context-aware evaluation of small and large language models: analysis code and data

This repository contains the analysis code and aggregated data for the article

> N. S. Stephane, G. Manzo, and P. Delgado, "Beyond Leaderboards: Deployment-Context-Aware
> Evaluation of Small and Large Language Models," submitted to *IEEE Access*.

The benchmarking framework, its configuration files, and the per-run results are
available at https://github.com/pameladelgado/TB-2026-SLM-benchmarking. This repository
contains the analysis built on top of them: it regenerates every derived number, table, and figure of the statistical and decision
analysis in the article: 95% intervals for task accuracy, Holm-adjusted comparisons,
uncertainty-aware Pareto sets, the worked deployment decisions (Algorithm 1), the
matched-checkpoint comparison, the Raspberry Pi request rates, the corrected
cost-effectiveness indicator, and the audit of the original Table 7.

## Repository layout

```
analysis/
  recover_figure_values.py   recovers plotted values from the vector figures of the results pipeline
  build_dataset.py           assembles data/aggregated_metrics.csv, recording the source of every value
  make_revision_outputs.py   computes all derived results; writes ../tables/rev_*.tex, ../figures/rev_*.pdf
  compute_supplementary.py   Supplementary Tables S1-S5 from the per-run result files of the
                             benchmarking repository (run-level intervals, energy intervals, paired tests)
  run_level_uncertainty.py   generic run-level/item-level analysis of per-sample logs
  stats_utils.py             Wilson, Newcombe, and Holm procedures
  tests/                     unit tests (reference values from the statistical literature)
  data/                      aggregated input data and all derived CSV files
tables/
  table_0*.tex               tables exported by the results pipeline (inputs)
  rev_table_*.tex            tables generated by make_revision_outputs.py
figures/
  figure_05/06/07_*.pdf      figures produced by the results pipeline (inputs to recover_figure_values.py)
  rev_fig_*.pdf              figures generated by make_revision_outputs.py
```

## Reproducing the results

Requires Python 3.9 or later.

```
cd analysis
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python recover_figure_values.py   # optional: re-derive data/recovered_from_figures.csv
python build_dataset.py           # data/aggregated_metrics.csv
python compute_supplementary.py --repo /path/to/TB-2026-SLM-benchmarking   # supplementary/s*.tex
python make_revision_outputs.py   # tables/rev_*.tex, figures/rev_*.pdf, data/derived_*.csv
python -m pytest tests -q
```

## Data provenance

`analysis/data/aggregated_metrics.csv` contains one row per deployment context, model
configuration, and workload (23 configurations x 4 workloads). For every value, a
`<field>_source` column records its origin, in order of precedence:

1. `tables`: tables exported by the results pipeline (`tables/table_0*.tex`);
2. `figure`: values recovered exactly from the vector PDF figures of the same pipeline;
   agreement with the overlapping table values is checked on every build (maximum
   deviation 0.09%);
3. `thesis`: Tables 8.1 and 8.2 of the B.Sc. thesis of S. Nascimento Santos (HES-SO, 2026),
   cached in `analysis/data/thesis_tables_8_1_8_2.csv`.

All accuracy values refer to the same fixed subset of 100 items per benchmark, presented
in a run-specific order in each of ten measured runs, with greedy decoding.

## Supplementary material

`supplementary/supplementary_material.pdf` (Tables S1-S5) is produced by
`compute_supplementary.py` from a local clone of the benchmarking repository:

```
git clone https://github.com/pameladelgado/TB-2026-SLM-benchmarking
cd analysis && python compute_supplementary.py --repo ../TB-2026-SLM-benchmarking
```

## Per-sample logs

`run_level_uncertainty.py` operates on the per-sample CSV files written by the
benchmarking framework (one row per measured request). Run
`python run_level_uncertainty.py --help` for the expected columns and options.
